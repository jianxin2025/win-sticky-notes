# WinStickyNotes 便签

一个基于 **PySide6** 的 Windows 桌面便签应用：无边框圆角窗口、置顶常驻、Markdown 编辑与预览、图片 / 视频内嵌，数据以纯文本 Markdown 落盘，随时可迁移、可版本管理。

## 功能特性

- **无边框圆角便签窗口**：自绘圆角背景，可自由拖动与缩放。
- **编辑 / 预览一键切换**：预览模式实时渲染 Markdown（支持表格、围栏代码块、列表等）。
- **图片与视频插入**：图片在预览中按比例显示；视频以内嵌播放器播放，支持 `mp4 / avi / mkv / mov / webm / wmv / flv / m4v`。
- **样式自定义**：字号、字体颜色、背景颜色、边框颜色均可调。
- **窗口置顶**：可将重要便签固定在最前。
- **系统托盘常驻**：托盘菜单提供「新建便签 / 便签列表 / 便签存储位置 / 退出」。
- **便签列表管理**：集中查看、打开、删除已保存的便签。
- **纯文本落盘**：每条便签保存为独立的 `.md` 文件，配合 `index.json` 元数据索引，数据透明、易于备份与迁移。
- **存储位置可配置**：支持相对项目根或绝对路径。
- **免安装单文件打包**：通过 PyInstaller 打包为无终端、免安装的单个 exe。

## 环境要求

- Windows 10 / 11
- Python 3.10+（开发 / 源码运行需要）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行（源码）

```bash
python notes.py
```

启动后程序常驻系统托盘，不会显示主窗口。单击托盘图标即可新建便签，右键托盘图标打开菜单。

## 使用说明

- **新建便签**：单击托盘图标，或在托盘菜单选择「新建便签」。
- **编辑 / 预览**：点击便签标题栏的编辑 / 预览按钮切换。
- **样式与插入**：点击设置按钮，可调整字号、颜色，或插入图片 / 视频。
- **置顶**：点击图钉按钮。
- **管理便签**：托盘菜单 →「便签列表」，查看 / 打开 / 删除便签。
- **存储位置**：托盘菜单 →「便签存储位置…」，修改后下次启动生效。

## 数据存储

默认保存在程序目录下的 `file/notes/`：

```
file/
├── config.json          # 应用配置（如存储位置）
└── notes/
    ├── index.json       # 便签元数据索引（位置、尺寸、样式、标题等）
    ├── note-<id>.md     # 每条便签的正文
    └── note-<id>/       # 该便签用到的图片 / 视频等附件
```

写入采用「临时文件 + 原子替换」，避免中途异常导致数据损坏。

## 打包为免安装单文件

项目已提供 PyInstaller 配置 `notes.spec`（`console=False`，即无终端窗口）：

```bash
pyinstaller --clean --noconfirm notes.spec
```

产物位于 `dist/WinStickyNotes.exe`，拷贝到任意有写权限的目录双击即可运行，无需安装 Python 或其它依赖。

## 项目结构

```
.
├── notes.py           # 应用主程序（单文件）
├── notes.spec         # PyInstaller 打包配置
├── requirements.txt   # 依赖清单
└── file/              # 运行时数据目录
```
